# g-chess

A chess game being built by my son.

Tap a piece to see where it can go, then tap a dot to move it. Play the
computer (easy, medium or hard) or a friend on the same screen. There's an
Undo button, a Hint button that lights up a good move, and the game remembers
where you were if you close it.

Tap 🏆 to see the leaderboard. Before a game, pick who's playing (🦊 Fox,
🐉 Dragon and friends). Every finished game counts: wins against the computer
on each level, and wins, losses and ties between friends. It's saved on this
device only.

New to chess? Tap 🎓 (or "Learn to play" in the New game window) for a path of
short lessons in four units: meet the pieces, capture, check and checkmate, and
special moves. You tap the squares a piece can go to, or make the move the
lesson asks for, and get told right away if it's right. Each lesson unlocks the
next one and earns up to 3 stars (fewer mistakes, more stars). Do a lesson every
day to grow a 🔥 streak. It's all saved on this device only.

## Getting started

```bash
npm install
npm run dev
```

Open the link it prints. To play on a tablet or phone on the same Wi-Fi, use
the "Network" link instead.

## Testing

```bash
npm test
```
